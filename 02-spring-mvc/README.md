# Spring MVC

Folder này ghi lại quá trình học Spring MVC cơ bản, bao gồm IoC/DI, Spring Container, ApplicationContext, request flow, Controller-Service-Repository, Thymeleaf view, form binding, validation và cấu hình Hibernate trong Spring MVC.

## Learning Topics

- Spring MVC overview
- IoC / DI
- Spring Container
- ApplicationContext
- DispatcherServlet
- Controller, Service, Repository
- Model, View, Request Mapping
- Thymeleaf template engine
- Form binding with POST method
- Validation and BindingResult
- Hibernate configuration in Spring MVC
- Common errors
